# 🧬 ژنتیک‌یار — بانک سوالات پیش‌بینی آزمون دکتری تخصصی ژنتیک پزشکی

بانک جامع آمادگی آزمون دکتری تخصصی ژنتیک پزشکی (وزارت بهداشت) شامل **سیلابس ۲۰ موضوعی هر فصل منابع اصلی + سوالات پیش‌بینی‌شده با پاسخنامه دو سطحی (درسنامه) + زبان تخصصی**.

## 📦 محتوا (فاز ۱ — کامل)

| بخش | حجم | توضیح |
|---|---|---|
| **سیلابس جامع** | ۵ کتاب × ۹۴ فصل × ۲۰ موضوع = **۱٬۸۸۰ موضوع** | هر موضوع با وزن احتمال طرح سوال (★ تا ★★★★★) بر اساس تحلیل آزمون‌های سال‌های قبل |
| **بانک کتاب امری ۱۶** | ۲۱ فصل × ۱۰ سوال = **۲۱۰ سوال** | چهارگزینه‌ای به سبک آزمون + پاسخنامه دو سطحی: سطح ۱ (پاسخ سریع + رد گزینه‌ها) و سطح ۲ (درسنامه کامل) |
| **زبان تخصصی** | **۱۲ ریدینگ + ۶۰ سوال** | بر اساس مقالات پوشه Breast cancer سیستم + مقالات ۲۰۲۴–۲۰۲۶؛ واژگان کلیدی + استراتژی پاسخ‌دهی + جدول واژگان پرتکرار |

**منابع:** Emery's 16e | Strachan HMG 5e | Strachan GGM 2e | Brown Gene Cloning | Harper's Biochemistry 2022

## 🚀 اجرای اپ موبایلی (PWA)

اپ فارسی راست‌به‌چپ، قابل نصب روی گوشی (افزودن به صفحه اصلی) و کارکرد آفلاین:

```bash
cd app
python -m http.server 8765
# مرورگر: http://localhost:8765
```

یا نسخه آنلاین روی GitHub Pages (پس از فعال‌سازی Pages در تنظیمات ریپو، از شاخه `main` پوشه `/app`).

**امکانات اپ:** مرور سیلابس ۵ کتاب | سوالات امری با خودآزمایی | حالت آزمون تصادفی با نمره | ریدینگهای زبان با ترجمه واژگان | جستجوی سراسری | پیشرفت مطالعه (localStorage) | آفلاین کامل (Service Worker)

## 📄 ساخت PDF فارسی

```bash
python tools/build_pdf.py
```

خروجی: `Genetics-PhD-Exam-Bank.pdf` — فایل راست‌به‌چپ با فونت وزیرمتن (جلد + سیلابس + سوالات + ریدینگها، ~۳۰۰ صفحه). نیازمند Edge یا Chrome روی سیستم.

## 🔁 بازسازی داده‌های اپ پس از تغییر محتوا

```bash
python tools/build_app_data.py   # ادغام content/ → app/data/bank.json
python tools/build_pdf.py        # بازسازی PDF
```
